Files (generated by `../make_print_files.py` from `../stl/moon4c_*_print.stl`; parts already in print orientation, on the bed, centred on a 180 x 180 plate so they fit every Bambu bed):

| File | Contents | Height |
|---|---|---|
| `plate2_coupons.3mf` | **print first**: C6 rear end of the plinth (USB-C opening, plug pocket, rear roof), C7 20 mm plinth slice (shelves, ribs, board slot) | 14.0 / 20.0 mm |

| `*.stl` | the same objects one by one | |

Open the 3MF in Bambu Studio (File > Open), keep the positions, pick PETG, then set the values below. The 3MF holds geometry only, no slicer profile.

## Order
0. Optional but cheap: the DFM spec also lists C1 (fit plate: display ring and board slot sizes) and C2 (snap coupon). They are not modelled yet; plate 1 contains the real snaps and window, so a first full print doubles as that test.
1. **Coupons (plate 2), PETG.** C6: push the real USB-C cable in, the overmould must seat; check the roof above the pocket is not sagging through. C7: slide the real PCB into the slot (should slide with light friction, held by the ribs), check the bridges.
2. **Parts (plate 1).** Assemble: plug the display into J2, slide the board into the plinth, press FACE on (about 21 N, it clicks), snap BACK in.
3. **Heat test (C8):** run the board in Wi-Fi mode for 2 hours in the assembled housing and touch or measure the plinth top over the ESP32. PETG is fine to about 70 degC; if it stays below 40 degC, PLA would also do.

Report back: USB fit, board slot feel, snap force and whether it clicks without white stress marks, bridge sag, ceiling temperature. The model is adjusted from that.

## Bambu Studio settings (PETG; PLA in brackets)

| Setting | Value |
|---|---|
| Plate | textured PEI |
| Layer height | 0.20 mm (optional: variable 0.12 mm for the first 1.2 mm of FACE and PLINTH, cleaner bed-edge chamfer) |
| Line width | 0.42 mm outer wall, 0.45 mm inner and first layer |
| Walls | 4 (1.68 mm) for FACE and PLINTH, 3 for BACK and the snap arms; "ensure vertical shell thickness" on |
| Wall order | inner/outer, "precise wall" on |
| Top / bottom shells | 4 layers |
| Infill | 15 % gyroid; 100 % in the FACE snap arms (height-range or modifier) |
| Seam | aligned, at the rear (the hidden underside); scarf seam if available, seam gap off on FACE |
| Ironing | off |
| Supports | **off** (all overhangs are designed self-supporting; the plinth's inner roofs are hidden bridges and may sag slightly) |
| Brim | **outer 5 mm on PLINTH** (tall part), 3 mm on FACE, none on BACK; coupons 3 mm; brim gap 0.1 mm |
| Elephant foot compensation | 0.10 mm |
| First layer | 0.2 mm, bed 70 degC [55], 25 mm/s |
| Nozzle | 245 degC [215] |
| Cooling | PETG fan 60 % after layer 3, 100 % on bridges and overhangs [PLA 100 %] |
| Speed | outer wall 60 mm/s, inner 100, bridges 30; acceleration 2000 mm/s2 (keeps the 56 mm plinth from wobbling) |
| Bridges | flow 0.95, thick bridges off, internal bridges auto |
| Arc fitting | on |
