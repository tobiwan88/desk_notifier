Desk Notifier Setup

Set up Wi-Fi, clock and name over Bluetooth, and find the IP address.

This browser cannot do Bluetooth

Use Chrome or Edge on Android or on a computer. On an iPhone, Safari has no Web Bluetooth: install the Bluefy browser and open this page there.

Needs HTTPS

Browsers only allow Bluetooth on pages served over HTTPS (or localhost). Open this page from its https address.

1. Connect

Power the notifier, then press the button and pick it from the list (it is named like its hostname, "squirrel" by default). The first time, a 6-digit code appears on its display: type it when your phone asks.
