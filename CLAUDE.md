# desk_notifier: agent notes

Desk notifier on an ESP32-C61: one GC9A01 round display, a BME688 (I2C), SNTP clock, web API. Split from the esp_eyes project (history kept).

## Tooling
- ESP-IDF v6.1 in `~/esp/esp-idf`. Activate with `source scripts/idf-env.sh` (never `export.sh`). Python via `uv run`. `ls` is aliased here: use `command ls`.
- `scripts/check.sh [--quick]`: core-include check, host doctest (ASan/UBSan, -Werror), pytest (`clipprep/`, `tools/`), `idf.py build`.
- Firmware: `cd firmware && idf.py build`; flash with `idf.py -p PORT flash monitor`.

## Layout
`firmware/components/<name>/{core,idf}`; `core/` is pure C++ (no `esp_*`/`freertos/` includes) and host-tested.
- `sensor` (airq score, BME688 driver, vendored Bosch BME68x API in `third_party/`), `screen` (font, AA shape rasterizer `draw.hpp`, pages: clock / squirrel air page / squirrel's day page (`day.cpp`), `Rotator`, render task), `weather` (Open-Meteo parse in core, HTTP fetch task in idf), `clock` (SNTP/TZ), `display`, `gfx`, `net`, `web`, `settings`, `storage` + `clip` (pictures, not yet shown), `engine` (errors/types only).
- Kconfig prefix `DESK_*`. NVS namespace is still `eyes` (keeps Wi-Fi credentials from the old firmware).

## Hardware (hardware/, see hardware/PLAN.md)
- notifier-v1 PCB (ESP32-S3-WROOM-1-N8R2, 4 layers, JLC-assembled) is generated, not hand-drawn: edit `hardware/gen/notifier_v1.py` (PARTS/NETS) and `hardware/gen/layout_v1.py` (placement), then `hardware/tools/pipeline_v1.sh [--bom]`. Gate: `scripts/hw-check.sh` (in `check.sh`). Order steps: `hardware/notifier-v1/ORDER.md`.
- Skills: `hw-base` (read first), `kicad-schematic`, `kicad-layout`, `hw-parts` are board-neutral; notifier-v1 facts are in its profile `hardware/notifier-v1/` (`BOARD.md`, `board.yaml`, `critical.yaml`, `parts/`). Numbers come from scripts in `hardware/calc/`.
- `source scripts/kicad-env.sh` for kicad-cli, `$KICAD_PYTHON` (pcbnew SWIG, Python 3.9) and the symbol/footprint dirs. Routing: KiCadRoutingTools in `hardware/.tools/` (gitignored; clone + `build_router.py`).
- Firmware for the PCB: `DESK_BOARD_NOTIFIER_V1` (default on S3); `idf.py -B build-s3 -DIDF_TARGET=esp32s3 -DSDKCONFIG=build-s3/sdkconfig build`.
- KiCad's IPC API runs in the KiCad project manager (KiCad.app), not in the standalone PCB Editor app.
- Housing (3D printed, Fusion): `hardware/mechanics/` (README.md, PLAN.md, STL/3MF/f3d). Display module dimensions there are assumptions until checked with `display_dummy.stl`.

## Board
Device identifiers (MAC, host name, LAN IP, serial port) live in `CLAUDE.local.md` (gitignored). The native USB-Serial/JTAG port (the console) did not enumerate on the Mac, so logs are not visible there; flash over the UART bridge. Check state over HTTP (`/api/status` shows `sensor.i2c` scan). BME688 answers at 0x77. Display is mirrored-X by default (`DESK_LCD_MIRROR_X`; unconfirmed on the panel). Kconfig bools set to `n` are undefined macros: use `#ifdef`, there is no `IS_ENABLED`.
GitHub: https://github.com/tobiwan88/desk_notifier (remote `desk`; `origin` is still the local esp_eyes clone source).

## Squirrel outfits
`outfit_for(weather_ok, Forecast)` in `screen/core/squirrel.cpp`: hat <8 C, ice cream >=25 C, sunglasses on sunny days, umbrella in rain (drops the ice cream), glider at wind >=30 km/h (`Forecast.wind_kmh`, `/api/weather` shows it). The clock page never shows the umbrella (peeking squirrel too small). Check layouts with `tools/preview_pages.py`; scenes live in `firmware/test/host/preview.cpp`.

## Status
Three pages rotate with a fade at CONFIG_DESK_FPS (default 10): clock (+ date, in/out temperature, today's low/high/rain, peeking squirrel), air (squirrel mascot, mood = air level: VERY GOOD/GOOD/OKAY/BAD, sleepy while warming up; sky behind it = outdoor weather via `screen/core/sky`; hat+scarf below 8 C, ice cream from 25 C outside), day (the squirrel at its desk; `activity_for()` in `screen/core/day.cpp` picks the scene from weekday + time + `Schedule` (Kconfig `DESK_DAY_*`, HHMM), never at random: sleep, coffee, work, lunch, close laptop, read; weekends and Bavarian holidays sleep in, no work. `scene_for()` adds a `Situation` (indoor climate/weather: party, smell via `AirTrend`, storm, air out, cool down, yawn, hot/cold room, humid, dry, umbrella, cocoa, watering; first match wins) and an `Occasion` (birthday/anniversary MMDD from Kconfig, Christmas, NYE, New Year, Easter, Nikolaus, St. Martin, Halloween, clock change, Oktoberfest, Squirrel Day, Valentine, April fool) plus Advent candles; drawing in `day_view.cpp`, props in `props_{calendar,env,window}.cpp` (`props.hpp`; check with `tools/prop_sheet.py`). Window = real sky via `sky::draw`, wall clock = real time. Small randomness lives in `screen/core/fun` (stateless: hash of time slot + `Inputs.seed`, seeded by `esp_random()` at boot): `Quirks` (blink, glance, ear, tail, hop, wave, acorn toss) applied in `draw_squirrel`, `Visit`s (bird, butterfly, ladybug, moth, shooting star) allowed per page by `allowed_visitors()`; clock squirrel pops up and waves on the full hour (`Inputs.millis`). Preview clips `fun_*`, `more_*`, `gag_*` start where the surprise happens. Also: seasonal visitors (owl, hedgehog, snail after rain via `RainWatch`, bee, leaves, petals), `fun::golden()` (rare, pins the air page, count in NVS `golden`), real moon via `cal::moon_phase` + howl on full moon/Halloween (wolf ears), `rainbow_alpha()` after rain (pictures use `weather::now_sky` = current code, outfit still the daily code), `Plant` in `screen/core/memory` (NVS `plant`, leaves/droop/flower from daily good-air share), countdown calendar 1..7 days to birthday/anniversary/Christmas, gags via `allowed_gags()`/`fun::gag()`, puns via `fun::pun()`. New props in `props_{critters,scenery}.cpp`. Friendship: `screen/core/bond` (`Bond`, `interact()`, `settle()`; levels never drop, NVS `bond`, name NVS `sqname`), reactions drawn on the air page by `friend_view.cpp` (pins the air page 12 s/20 s), perks by level (hello waves, lucky golden acorn, fox/friend visitors, present, gift shelf, name). Pet page `web/ui/pet.html` at `/pet`, API `GET`/`POST /api/pet` (open, no token); `screen::pet()/pet_status()/set_pet_name()` in the screen task (std::mutex). Preview clips `pet_*`, `perk_*`. Shop: `screen/core/shop` (31 items, `daily_offer()` 6/day by date hash, seasonal only in season, `buy()`, `look_for()` = the squirrel's own pick per half day, new item worn on its day); coins in `Bond` (`earn()`, trickle before level 5, NVS `b2` format, still loads `b1`); `dress()` puts hats/glasses/clothes on in `draw_squirrel`; places/friends on the air page, decor on the day page; unboxing = `Reaction::unbox` in `friend_view.cpp`; coins found via `fun::coin_found()`. Props in `props_{wear,places,home}.cpp`. API `GET`/`POST /api/shop`. Clips `shop_*`. The old weather page was removed as a duplicate of the air page's sky; `page weather` is an alias for `day`). Poor air pins the air page until ack; button = ack during an alert, else next page. API: `GET /api/status`, `GET /api/sensor`, `GET`/`POST /api/pet`, `GET`/`POST /api/shop`, `GET`/`POST /api/weather`, `POST /api/page` (clock/air/day/next), `POST /api/ack`, `POST /api/ota`, clips CRUD. Console: `page`, `weather`.
Preview pages on the host: build host tests, then `uv run python tools/preview_pages.py` (GIFs + sheet.png in build/preview; add `matrix` for all weather x mood x day/night x temperature sheets).
The C61 has no FPU: keep per-pixel work integer (see `draw::fill`), floats only per span/row.

## Private data (this repo is public)
Never commit: Wi-Fi names/passwords, tokens, MAC addresses, host names, LAN IPs, serial ports, home paths (`/Users/<name>`), real birthdays/anniversaries/names, photos of people or the home, order/account data, Fusion/KiCad files with user metadata. Kconfig defaults for personal values stay at 0 / "" (real values go in the ignored `firmware/sdkconfig`); device notes go in `CLAUDE.local.md`.
- Before every commit that will be pushed, and before a push: `scripts/privacy-check.sh` (scans tracked files and the staged diff; extra personal strings go in the gitignored `.privacy-patterns`, one extended regex per line). Fix findings, do not suppress them.
- New binary/CAD exports (`.f3d`, `.3mf`, gerbers, images): check embedded metadata for names and paths before adding.
- History rewrites for private data need the user's explicit OK; GitHub keeps old commits reachable through pull-request refs until support purges them.
